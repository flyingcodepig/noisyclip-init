# 实验目录

## 共同控制条件

除唯一变量外，所有实验固定：

- 相同官方训练集和固定 train/val manifest；
- 相同 CLIP ViT-B/32 官方权重；
- 相同输入尺寸、基本增强、训练 epoch/step 预算；
- 相同优化器、学习率策略、batch 等效大小；
- 相同随机种子序列；
- 相同最佳 checkpoint 选择规则；
- 相同评估代码和指标定义。

每个实验都必须保存 resolved config、环境快照、epoch 指标、最佳与最终 checkpoint、per-class 指标和书面结论。

## S0：系统冒烟实验

**目的**：验证数据、模型、反向传播、保存恢复、推理和 CSV 链路，不评价算法优劣。

**配置**：3个类别的小型固定 fixture 或每类少量训练样本；2个 optimizer steps；1次验证。

**步骤**：数据审计 -> forward/backward -> 保存 -> 恢复 -> 推理 -> CSV 校验。

**记录**：张量形状、可训练参数、单步 loss、峰值显存、checkpoint 哈希。

**停止条件**：任何 NaN、类别映射不一致、恢复输出不一致、原始数据可写。

## B0：冻结 CLIP + Linear Head

**研究问题**：不适配骨干时，CLIP 冻结视觉特征能达到什么基础水平？

**唯一配置**：backbone 全冻结；普通线性分类头；CE；不启用可信度、ELR、teacher、一致性、伪标签。

**步骤**：

1. 审计数据并固定划分。
2. 加载官方 CLIP，验证全部 backbone `requires_grad=False`。
3. 训练 linear head。
4. 重新加载最佳和最终 checkpoint 评估。

**重点记录**：Top-1、Macro、per-class、训练-验证差、吞吐、冻结特征可分性。

**必须保存**：类别映射、固定 manifest、最佳 head、基础混淆矩阵。

**灾难点**：误将 backbone 加入 optimizer；类别索引按整数而不是原始字符串生成。

## B1：Cosine Head + 鲁棒原型初始化

**研究问题**：余弦分类与原型初始化是否更适合 CLIP 表征？

**相对 B0 唯一变化**：head 改为 cosine；使用冻结特征的截断/加权均值原型初始化。

**步骤**：先提取训练特征 -> 构建每类初始中心 -> 剔除距离中心最远的小比例仅用于重算原型、不删除训练样本 -> 初始化 head -> 按 B0 预算训练。

**重点记录**：初始 epoch 指标、收敛速度、原型类内/类间距离、温度值。

**必须保存**：初始和最终 prototypes、原型构建参数、特征缓存 digest。

**停止条件**：存在缺失类别；原型出现零范数/NaN；原型缓存与数据 digest 不匹配。

## B2：后层 LoRA

**研究问题**：有限视觉适配是否提高细粒度识别，同时保持 CLIP 先验？

**相对 B1 唯一变化**：最后2-4个视觉 Transformer block 的 attention q/v 注入 LoRA，默认 rank=8；head 与 LoRA 使用分组学习率。

**步骤**：注入 -> 打印参数白名单 -> smoke backward -> 训练 -> 统计特征漂移 -> 合并 LoRA 验证。

**重点记录**：可训练参数数量/比例、Top-1、Macro、特征余弦、训练-验证差、显存和吞吐。

**必须保存**：未合并 checkpoint、合并模型、参数审计报告、输出等价报告。

**立即停止**：前层或未授权参数出现梯度；特征余弦突降；合并前后预测不一致。

## B3：类内可信度连续加权

**研究问题**：联合可信度能否降低错标样本梯度影响，而不误删困难样本？

**相对 B2 唯一变化**：启用 EMA loss、增强一致性、原型相似度/margin、稳定性信号；类内归一化后产生连续监督权重。

**步骤**：先 warmup -> 收集逐样本信号 -> 类内归一化 -> 生成三分区和连续权重 -> 每2-5轮事务化更新。

**重点记录**：各信号分布和相关性、每类分区比例、权重直方图、Top-1/Macro/后四分位、疑似样本预测变化。

**必须保存**：每次更新的 sample state parquet、信号权重、分区摘要。

**立即停止**：大量样本权重为 NaN；某些类别全部变成 suspicious；sample_id 重复或状态行数变化。

## B4：ELR

**研究问题**：ELR 是否减轻后期记忆噪声？

**相对 B3 唯一变化**：warmup 后启用 ELR；其余不变。

**步骤**：初始化逐样本历史预测 -> warmup 期间只更新不施加正则 -> 指定 epoch 启用 -> 保存最佳与最后模型。

**重点记录**：最佳轮到最后轮的 Top-1 下降、训练-验证差、ELR loss、预测历史熵。

**必须保存**：ELR 状态版本、恢复一致性报告。

**立即停止**：历史预测按 batch 索引而非 sample_id 错配；ELR 突然主导 total loss；恢复后状态缺失。

## B5：冻结 CLIP 特征保持

**研究问题**：feature anchor 能否减少灾难性遗忘并提升稳定性？

**相对 B4 唯一变化**：冻结官方 CLIP 作为训练期 teacher，加入 student/teacher feature cosine loss。

**步骤**：验证 teacher 全冻结和 eval -> weak view 同步编码 -> 计算 detach teacher target -> 训练 -> 统计分层特征漂移。

**重点记录**：Top-1、Macro、feature cosine、训练吞吐、峰值显存、不同类别的漂移收益。

**必须保存**：teacher 权重哈希、anchor 权重、漂移分布；teacher 不进入导出包。

**立即停止**：teacher 有梯度；teacher 和 student 预处理不同；导出模型仍依赖 teacher。

## B6：弱/强增强一致性

**研究问题**：不依赖标签的一致性信号是否进一步利用不确定样本？

**相对 B5 唯一变化**：增加 strong view 和 detached weak prediction consistency loss。

**步骤**：固定 weak/strong 变换 -> 对齐 sample_id -> 高置信或全样本加权一致性 -> 监控预测熵和塌缩。

**重点记录**：增强一致率、损失占比、细粒度困难类别、吞吐和显存。

**必须保存**：增强配置、随机参数摘要、按可信分组的一致率。

**立即停止**：强增强产生空白/严重裁剪图比例异常；类别预测熵快速接近0；consistency target 未 detach。

## U1：严格门控软伪标签

**目的**：修复长期与视觉证据冲突的疑似错标签。

**唯一变化**：在冻结主线上启用后期软伪标签；不得完全覆盖原标签。

**门控条件**：多轮预测稳定、弱强增强一致、高置信、原型 margin 足够大、原标签长期低可信，且伪标签类别不过度集中。

**重点记录**：启用样本数、原->伪类别转移矩阵、每类伪标签流入/流出、伪标签精度代理指标。

**立即停止**：伪标签覆盖率超过预设上限；少数类别吸收大部分伪标签；验证 Macro 明显下降。

## U2：显式课程学习

**目的**：先学习可信模式，再逐渐纳入不确定样本。

**唯一变化**：监督权重随 epoch 调度；可信样本先进入，uncertain/suspicious 后进入。

**重点记录**：每轮有效样本量、各分区梯度贡献、收敛速度、困难类别恢复情况。

**风险**：课程过慢导致欠拟合，过快等同无课程；早期错误可信度会固化偏差。

## U3：每类多原型

**目的**：表示同一类别的姿态、性别、生命周期或背景多模态。

**唯一变化**：单原型改为每类 K 个原型；K 固定且小，或按样本数受限选择。

**重点记录**：各原型分配样本数、空簇、类内覆盖率、原型 margin 变化。

**立即停止**：大量空簇；小类别被强制拆分；原型变成背景聚类并伤害 Macro。

## U4：条件式类别均衡

**目的**：仅在初赛数据审计确认明显不均衡时减轻头部类别偏置。

**唯一变化**：平方根采样、受限 class weight 或小幅 logit adjustment 三者一次只测一种。

**重点记录**：类别数量分布、头/中/尾 Top-1、Macro、重复采样率、尾类疑似噪声暴露次数。

**立即停止**：尾类训练损失剧烈振荡；头类下降远大于尾类收益；噪声样本被高频重采样。

## U5：TrustCLIP 风格可信梯度约束

**目的**：限制可疑样本梯度与可信方向冲突。

**唯一变化**：加入梯度投影/对齐模块；先在 head 或 LoRA 参数子集验证。

**重点记录**：冲突梯度比例、投影前后范数、额外时间、Top-1/Macro、数值稳定性。

**立即停止**：梯度范数接近零、训练吞吐不可接受、出现高频 NaN、实现改变基线关闭状态。

## U6：JoAPR 风格自适应分区与标签翻修

**目的**：比固定类内百分位更自适应地识别并修正噪声。

**唯一变化**：替换 B3 的分区器；其余损失和模型固定。

**重点记录**：分区阈值、分区稳定性、标签转移矩阵、困难类别保留率、额外计算成本。

**立即停止**：阈值振荡、某类可信样本清空、重标注比例无约束增长。

## 组合实验

只有单独通过准入的模块才能组合。组合实验需要回答交互问题，例如：

- U1 软伪标签是否依赖 B3 可信度？
- U2 课程学习是否改变 B4 ELR 的最佳启用时间？
- U4 类别均衡是否破坏 B3 的 loss 分布？
- 更大 LoRA rank 是否需要更强 B5 feature anchor？

组合实验不得把多个未经验证模块一起加入。
