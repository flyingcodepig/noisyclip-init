# 模块准入与淘汰规则

## 1. 主指标和保护指标

主指标：固定验证集 Top-1 Accuracy。

保护指标：

- Macro Accuracy；
- 后25%类别平均准确率；
- 高可信验证子集 Top-1；
- 最佳 epoch 到最终 epoch 的性能下降；
- 与冻结 CLIP 的特征余弦相似度；
- 多随机种子标准差；
- 显存、训练时间和推理成本。

由于验证标签也可能有噪声，任何模块不能只凭单次 Top-1 判断。

## 2. 初筛规则

单种子实验满足以下条件进入复验：

1. Top-1 提升大于 `max(0.2个百分点, 基线历史单种子波动)`；或 Top-1 持平但 Macro/后四分位有清晰提升。
2. 高可信子集 Top-1 不出现明显下降。
3. 没有类别预测塌缩、训练不稳定或合规风险。
4. 资源成本在预登记预算内。

`0.2个百分点` 只是启动期阈值；获得三个以上基线种子后，使用实际波动更新。

## 3. 复验规则

至少两个种子后，模块分类为：

- **ACCEPT**：每个种子方向一致，平均提升超过基线标准差，保护指标无实质恶化。
- **CONDITIONAL**：收益依赖种子/类别，或仅改善 Macro，需要进一步分析和第三种子。
- **REJECT**：平均无提升、方向不一致且方差大、保护指标明显受损、资源成本不合理或存在合规风险。

## 4. 组合准入

组合中的每个模块必须已单独 ACCEPT。组合相对于较强单模块继续比较，而不是只对原始主线比较。

若 A、B 单独有效但 A+B 无额外收益，优先保留：

1. 方差更小者；
2. 保护指标更好者；
3. 实现更简单者；
4. 训练/推理成本更低者。

## 5. 最终方案选择

最终模型不是验证 Top-1 最大的单次 run，而是满足以下目标的最小模块集合：

```text
高平均 Top-1
+ 可接受 Macro/困难类别表现
+ 低种子方差
+ 低噪声记忆迹象
+ 可复现
+ 单模型合规
+ 可承受训练成本
```

必须书面记录被排除但最高单次分数更高的方案，以及排除原因。

## 6. 线上成绩使用原则

初赛线上分数可以验证提交链路和最终候选，但不能被当作高频超参数搜索的验证集。频繁根据榜单微调会造成对隐藏测试集的人工过拟合。建议只提交：

- 可用性基线；
- 主线冻结版本；
- 经离线复验的少量候选；
- 最终版本。
