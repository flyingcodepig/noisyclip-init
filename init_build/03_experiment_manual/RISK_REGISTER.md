# 风险登记与灾难性操作清单

## P0：必须立即停止

### 1. 测试集泄漏

**触发方式**：测试图片进入训练 DataLoader、原型、阈值、BatchNorm统计、自监督、一致性或伪标签流程。

**后果**：违反赛题规则，成绩可能无效。

**保护**：测试根只读且独立；manifest digest 和路径/哈希交集预检；训练代码拒绝 `split=test`。

### 2. 类别映射漂移

**触发方式**：不同脚本分别排序目录；把 `0001` 转成整数1后重建；默认类别从0或1连续。

**后果**：模型看似正常，但全部提交标签错位。

**保护**：唯一 `class_to_idx.json`；checkpoint 和导出包保存 mapping digest；推理只从模型包读取映射。

### 3. 原始数据被修改或删除

**触发方式**：清洗脚本移动/删除图片；把转换后图片覆盖原文件。

**后果**：数据不可恢复、实验不可复现，可能泄漏人工清洗过程。

**保护**：容器只读挂载；清洗只生成 manifest 和权重；脚本无删除权限。

### 4. 未授权参数被训练

**触发方式**：冻结逻辑失效，optimizer 包含整个 CLIP，或 teacher 未冻结。

**后果**：显存暴增、噪声记忆、灾难性遗忘，结果与实验假设不符。

**保护**：启动和每轮参数白名单审计；backward smoke test 检查梯度。

### 5. NaN/Inf 后继续训练

**触发方式**：过大学习率、AMP 溢出、零权重除法、异常原型、梯度投影数值错误。

**后果**：权重、optimizer、ELR历史和样本状态同时污染，之后 checkpoint 不可信。

**保护**：首次非有限 loss/gradient 即停止；不覆盖最后有效 checkpoint；保存诊断 batch ID。

### 6. Checkpoint 与样本状态不同步

**触发方式**：先覆盖状态再保存模型，过程中断电；恢复不同 epoch 的 ELR/可信度状态。

**后果**：恢复训练行为不可解释，损失可能突然异常。

**保护**：版本号、临时写入、原子提交；checkpoint 引用确切 state version。

## P1：高风险，达到阈值安全停止

### 7. 伪标签确认偏差

信号：伪标签快速集中到少数类、覆盖率失控、预测熵骤降、Macro下降。

措施：提高门限、降低伪标签权重、延后启用；不得在运行中手工改阈值，创建新实验。

### 8. 硬过滤困难样本

信号：某类几乎无可信样本、后四分位准确率下降、可疑样本多为遮挡/特殊姿态。

措施：连续权重、类内排名、每类最低有效样本保护；默认不删除样本。

### 9. 类别均衡放大噪声

信号：小类别可疑样本被频繁重复采样、训练 loss 振荡。

措施：先验证初赛是否真的长尾；使用平方根而非完全逆频率；采样权重设置上限。

### 10. 强增强破坏细粒度线索

信号：weak准确率正常但strong预测随机；局部结构被裁掉；一致性 loss 长期很高。

措施：限制裁剪 scale、颜色变化和 RandomErasing；保存增强样例做预训练前视觉审计。

### 11. 特征保持过强或过弱

过强导致适配不足，过弱导致遗忘。必须同时记录 Top-1 和 feature cosine，不能单独追求高相似度。

### 12. 多个实验争抢同一 GPU

后果：OOM、吞吐异常、不可比的温度/时钟变化。使用 GPU 锁和调度队列；一个 GPU 同时一个训练 run。

## P2：工程风险

### 13. 磁盘写满

可能导致半个 checkpoint、日志缺失和容器异常。每轮检查空间；至少保留预计 checkpoint 两倍空间；先安全停止再清理。

### 14. SSH 断开导致训练中止

使用 tmux/systemd/调度器，日志写文件。不要依赖前台 SSH shell。

### 15. 运行目录覆盖

脚本必须使用唯一 run ID，并在目录已存在时失败。禁止 `--force` 覆盖正式实验。

### 16. 环境漂移

禁止实验中途升级包；保存容器 image digest、pip freeze 和驱动信息。更换环境后先重新跑 B0。

### 17. 损坏图片处理不一致

数据审计和训练必须调用同一 `image_io`；读取失败策略由配置确定并记录，不能某些进程跳过、某些进程保留。

### 18. 用线上榜单过度调参

多次根据隐藏测试成绩选超参数会形成测试集人工过拟合。线上提交只用于少量里程碑版本。

## 安全停止步骤

1. 请求训练器在当前 optimizer step 或 epoch 边界停止，不直接杀进程。
2. 写入诊断 checkpoint 和 `STOPPED_SAFELY`。
3. 保存错误前最近若干步指标、sample IDs、梯度范数和显存状态。
4. 不提交当前未验证的 sample state。
5. 保留最后有效 checkpoint。
6. 新建实验 ID 修复，禁止在原 run 目录继续覆盖。
