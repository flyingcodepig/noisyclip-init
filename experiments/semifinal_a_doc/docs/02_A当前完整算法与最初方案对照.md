# A当前完整算法策略与最初方案的区别

整理日期：2026-10-30。本文以**实际完成并生成半决赛提交包的A**为准，而不是把所有试验赢家或外部报告建议叠加后的设想。实验及负结果总账见[01_全部实验与算法路线总账.md](01_全部实验与算法路线总账.md)。

## 1. 当前A到底是哪一版

当前半决赛A是：

> 官方CLIP ViT-B/32视觉骨干，448输入，原硬前景／背景零门控残差，单余弦分类头；全量噪声训练，非混合GCE、混合鲁棒GCE、CBD、冻结教师约束、原可信对比队列和动态弱／强视图EMA软一致性；主日程＋短低学习率收尾；导出尾段EMA这一套单模型权重；四视图概率平均，512/768分空间图等权传播，传播内及最终类别均衡。

没有使用显式全局／局部双头、软池化、LoRA、永久标签重写、聚焦裁剪或模型集成。双头属于另一条已完成迁移的备选路线，不是当前A的隐藏组件。

## 2. 数据处理与训练前派生输入

### 2.1 数据边界

训练只使用本阶段有噪声的训练图及其标签。测试图不进入梯度更新、训练原型、候选生成、教师训练目标或可信历史；只在固定无参数更新的转导读出时共同构图和均衡。

当前半决赛不划噪声验证集、也不调用复赛clean_protocol/dev.csv选模。阶段迁移先以干净复赛开发实验冻结方法，再用有限半决赛官方反馈判断实际效果。事后把已经训练过的图片切出不能变成独立验证集。

### 2.2 图像与缓存

1. 原图读取RGB并处理EXIF方向。
2. 完整视图按长宽比居中padding，填充CLIP均值色。
3. 中心视图显式保留短边6/7的中心方形区域，缩为384；完整视图和中心视图不会因原图方形而自动重合。
4. 只缓存384中心uint8图，训练输入再缩放448。完整图按需解码；没有把原图强行全部提前缩成低清训练来源。
5. 本阶段90,197图完整中心缓存约37.2GiB，放共享内存；这与早期复赛133,825张缓存＋14,870张原图读取的布局不同，但复赛也实际训练全部148,695张。

增强由样本gid、epoch和seed确定；采样器可由已完成更新数恢复偏移，预取不会改变恢复后的数据位置。相同字节文件使用同一canonical ID，避免同内容图成为对比正／负样本。

### 2.3 冻结官方教师、原型、LOO和候选

先用冻结官方视觉模型分别提取完整／中心视图512维归一化特征，再将两视图平均后归一化，得到每张训练图的静态teacher目标。

按本阶段训练标签汇总特征，归一化得到每类原型：用于head初始化，并构造训练可靠性与候选；不使用开发或测试真值。

对训练图自己的类别，使用扣除该图特征后的leave-one-out中心参与相似度比较。冻结特征的LOO预测是否同意原标签，作为原可信队列的一项条件。

每张图的候选集合至少含原标签；只有完整／中心两视图的原型预测都指向同一个非原类别，且各自top1−top2余弦间隔≥0.03，才增加一个候选。候选至多两个，不动态永久扩写。

原参考文档没有完整定义候选构造，本规则是最初独立重建时已明确补充的设计，不是A阶段才新增。早期半决赛训练切分新增514个训练候选；全量阶段重算日志为560个。增加来自数据参与和派生输入重算，不能当作一次候选扩展实验。

## 3. 模型结构：A沿用原结构

### 3.1 CLIP视觉骨干

- ViT-B/32，12层，隐藏768维，视觉投影512维。
- 输入448，patch网格14×14。
- 官方7×7 patch位置编码bicubic插值到14×14，CLS位置保持；位置编码参与微调。
- visual_projection参数冻结；其他视觉骨干以不同学习率微调。冻结线性投影仍向其输入传递梯度，768空间不是未训练空间。

### 3.2 前景／背景残差池化

设最后层CLS为c、patch为t_i：

\[
s_i=\cos(c,t_i),\quad M=\operatorname{TopK}_{24\%}(s).
\]

前景仅在M中按`softmax(s_i/τ)`加权，初始τ=0.135、范围[0.025,0.35]；背景为其余patch平均。

\[
u=c+0.28\tanh(g)\operatorname{LN}(foreground-background).
\]

g零初始化，差分LN无affine。初始化时新增残差为0，不扰动原CLS。对u施加CLIP原post-layernorm得到768视觉向量，再经过冻结投影和L2归一化得到512特征f。

这是一种CLS-patch余弦前景先验，不是真实分割、不是attention rollout。当前A保留硬top24%，没有采用第五轮的连续sigmoid mask。

### 3.3 余弦head

\[
z_j=\exp(a)\, f^\top \operatorname{normalize}(W_j).
\]

W用本阶段视觉原型初始化；head scale初值30，可学习并限[1,100]。A只有一个head，不等于local_global中的两头融合。

输出两个推理表示：归一化512特征f和归一化768视觉向量v，后续分别构图。

## 4. 训练监督

### 4.1 原标签鲁棒损失与CBD

对候选集合S_i：

\[
\ell_i=\log\sum_{c\in S_i}\operatorname{softmax}(z_i)_c,\qquad
G_q(\ell_i)=\frac{1-\exp(q\ell_i)}q.
\]

原标签为y_i，CE地板仍针对硬原标签：

\[
R_i(q)=0.975G_q(\ell_i)+0.025\operatorname{CE}(z_i,y_i).
\]

CBD按各类训练图数量n_c计算：

\[
\widetilde w_c=\frac{1-\beta}{1-\beta^{n_c}},\quad
w_c=\widetilde w_c/\operatorname{mean}_{c}(\widetilde w_c),\quad\beta=0.999.
\]

非混合微批分类损失为`mean(w[y_i] R_i(0.72))`。候选集合内概率求和没有除候选数，不能用均匀平均候选概率替代并声称等价。

### 4.2 A相对原算法的第一项核心变化：混合也鲁棒化

MixUp和CutMix互斥，各概率0.27，未混合概率0.46。强增强后混合，几何实际lambda用于CutMix；MixUp alpha0.19，CutMix alpha0.76。

最初混合分支是两侧候选部分CE，各自乘来源类别权重。A沿用R1的修改：

\[
L_{mix}=\operatorname{mean}\left[\lambda w_{y_i}R_i(0.4)
+(1-\lambda)w_{y_{\pi(i)}}R_{\pi(i)}(0.4)\right].
\]

两侧都对同一混合学生logits计算，使用各自来源图候选和硬标签。不能把非线性GCE直接施加到一个含混的“混合标签索引”。原始混合已有CBD，新增的是鲁棒目标，不是补上原先缺失的类别权重。

冻结teacher特征目标也按相同混合比例加权后归一化。混合图不作为可信对比锚点或入队。

### 4.3 第二项核心变化：动态弱／强视图EMA软一致性

EMA参数每次更新后：

\[
\theta_{EMA}\leftarrow0.999\theta_{EMA}+0.001\theta_{student}.
\]

EMA看弱中心视图及随机翻转，学生看强增强。对同一canonical训练图，记录上次教师预测、是否高置信、访问步数；只有满足以下条件才可信：

- 当前和上次访问均p_max≥0.9，top1−top2≥0.4；
- 两次top1相同，来自不同更新；
- 距上次访问不超过1242步，且已到启动步932。

复赛对应1536启动／512ramp／2048最大间隔；半决赛按曝光换算为932／311／1242。这里历史记录是两次访问的预测稳定性，不是拥有真实噪声标签的检测器。

仅非混合分支，教师target为原温度1的完整softmax，停止梯度，软损失是soft CE而不是把teacher argmax硬写入标签。可信项按教师预测类作batch内重加权：每个已覆盖预测类总权重相同，并保持总权重为可信样本数；最后除整个微批大小。这样早期稀疏可信集合不会被重新放大成满batch强度。

权重：

\[
\lambda_{soft}(t)=0.30\operatorname{clip}\left(\frac{t-932}{311},0,1\right).
\]

**保留原标签R_i，同时额外添加软目标；没有永久纠正标签，也没有用teacher把原监督完全替换。** 在该非混合分支，原EMA特征Huber被置零，由预测一致性替代；混合分支仍保留EMA特征Huber。

复赛日志显示可信样本绝大多数与原标签一致，教师冲突只占全曝光约1%。因此A应称“动态软一致性，具备有限软纠错可能”，不能称已验证的大规模精确纠错。

### 4.4 继承的三个约束与原可信队列

| 约束 | 当前定义 | 系数 |
|---|---|---:|
| 冻结官方teacher漂移 | 学生512特征与静态双视图teacher的smooth-L1，beta0.1 | 0.045 |
| EMA特征一致性 | 学生与同输入EMA512特征smooth-L1，beta0.1；仅混合分支保留 | 0.02 |
| L2-SP | 可训练backbone参数对官方初始化参数的平方差，按参数总数平均 | 0.0068 |
| 原可信SupCon队列 | 同类可信正对＋同内容排除的对比目标 | 0.031 |

原队列每类8条、最大年龄256步、128步后允许入队，contrast温度0.1。可信条件为学生预测同意原标签、p≥0.5、margin≥0.2、冻结LOO一致。可信锚点及可信同类keys形成正样本，分母仍允许原实现中的其他非同内容keys；并没有改成B那种“所有负样本也必须动态可信”。历史特征停止梯度，当前微批在优化器更新后入队。

总目标可概括为：

\[
L=L_{classification}+0.045L_{frozen}+0.02L_{EMA-feature}
+0.031L_{contrast}+\lambda_{soft}L_{soft}+0.0068L_{SP}.
\]

`L_soft`仅非混合存在；该分支的`L_EMA-feature=0`。以上项不是全部在所有微批同时非零，不能把系数简单相加解释成损失占比。

## 6. 四视图、先验和E1转导读出

### 6.1 四视图

| 视图 | 构造 | 概率权重 |
|---|---|---:|
| 0 | 完整图padding视图 | 0.23 |
| 1 | 6/7基础中心视图 | 0.16 |
| 2 | 基础中心再取0.86尺度并翻转 | 0.21 |
| 3 | 基础中心再取0.74尺度 | 0.40 |

均输入448。每视图posterior=`softmax(logits/2.85)`，按上表混合；2.85>1是平滑，不是锐化。512与768特征分别按四视图**等权**均值后归一化，和概率加权不同。

无第五聚焦视图，E1也没有重新训练权重。

### 6.2 head prior与初始均衡

以当前导出EMA的训练head W计算：

\[
p_{head}=\operatorname{softmax}(15f\operatorname{normalize}(W)^T),\quad
p_{mix}=0.94p_{4view}+0.06p_{head}.
\]

这是训练后head，不是冻结初始化原型，不应拿静态teacher中心替代。对p_mix做初始log-domain Sinkhorn，温度epsilon0.39、strength1、60迭代，得到固定seed s。

### 6.3 E1：分别建立两个空间的图

512特征f、768视觉特征v分别计算余弦22近邻，均排除自身。每空间边权：

\[
\widetilde w_{ij}=\exp((cos_{ij}-1)/0.07)
\cdot\max_c s_{jc}\cdot\max(cos_{ij},10^{-6})
\cdot(0.2+0.8\mathbf1_{mutual}).
\]

各空间独立按行归一化得到P512、P768，再：

\[
P=0.5P_{512}+0.5P_{768}.
\]

实现中拼接最多44条邻边贡献，重复邻居权重在求和时等价相加。**它不同于先拼接特征选22个邻居的joint图**，也不是两个模型的集成。

### 6.4 传播与中间均衡

每图系数：

\[
a_i=0.984[0.63+0.37(1-\max_c s_{ic})].
\]

从q⁰=s开始，共8轮：

\[
q_i^{t+1}=(1-a_i)s_i+a_i\sum_jP_{ij}q_j^t.
\]

每轮归一化，锚点始终是原seed。第2、4、6轮结束，再执行T0.90、strength0.60、30迭代的Sinkhorn，然后继续传播。0.63是邻居传播的系数底线，不是至少保留63%自身概率。

最终执行T0.78、strength1、100迭代Sinkhorn，argmax映射到本阶段四位类别编码。所有49,857测试图共同参与该固定读出，模型参数不变。

Sinkhorn在这里约束软列质量；strength1趋近均匀软质量，不保证硬argmax每类刚好约100张。真实测试类别先验未由标签确认；没有根据复赛公布标签的类计数、半决赛预测计数做硬配额或补类。

### 6.5 备用读出

同一EMA权重及四视图缓存另输出joint_balance备用包：512/768归一化拼接，联合22邻居，保留中间／最终均衡。E1在复赛开发上有小幅优势，但保留分别净少1/2张，因此备用joint仍有价值，不能把E1写成毫无争议的稳定优胜。
