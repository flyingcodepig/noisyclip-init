## 方法摘要

只使用规定的官方 CLIP ViT-B/32 初始化。保持原 32×32 patch 卷积核，stride 从32改为16；448 输入对应27×27 patch。官方7×7位置编码**直接**双三次插值至27×27（`align_corners=False`）。单个学生模型完整使用半决赛90,197张训练图训练，4,551主步＋311尾步，有效 batch192、seed41291，最终取 EMA 权重。它与队友另一个 FD1-G 的两段位置插值实现不同。

v4 读出使用同一权重的四视图概率，在固定模型后做 power1.1。无标签查询特征按各维最小值平移、开平方并 L2 归一化；**训练后的类别头固定不更新**，应用同一特征变换。余弦相似度与模型对数后验结合，经 Sinkhorn 做均匀类别软边缘后 argmax。没有在测试特征上重新拟合动态类中心，也没有测试数据梯度更新、测试标签、独立模型集成或 E1 图传播。

## 环境与复现

原环境：Python `/root/miniconda3/envs/myconda/bin/python`，PyTorch `2.6.0+cu124`，Transformers `4.46.3`，NumPy `2.1.2`，Pillow `11.0.0`，NVIDIA A100。官方 CLIP ViT-B/32 权重及赛事数据需按比赛规则单独取得。

代码快照原本作为 `dense_src/` 放在运行目录；本仓库改用 `src/` 归档。原 `scripts/run_dense_full.sh` 包含当时服务器绝对路径，并复用了**由本阶段全部90,197张训练图**构建的 `prepared/train_inputs.npz`；这是执行记录，不是可在任何目录直接运行的一键脚本。复现时先用 `src/prepare.py` 在本阶段训练集上生成教师资产，再按 `config.dense_full.json` 从官方权重训练，最后用 `src/deliver.py --save-cache --cache-only` 生成无标签测试缓存，调用 `scripts/fixed_balance_readout.py --feature-power` 得到 v4 CSV/ZIP。不得复用复赛资产或把研究留出权重当作正式权重。

克隆后运行 `git lfs pull` 才能取得完整 `.pt` 权重；Git LFS 指针本身不能加载为模型。
